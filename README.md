# Получение позиций DXF из CSV

Программа получает позиции (DXF) из CSV-файла двумя способами:

1. **Из АРМа** — позиции загружаются напрямую из АРМа.
2. **Из папки Мосин** — позиции загружаются из папки Мосин.

## Зависимости

- [Apache PDFBox](https://pdfbox.apache.org/) `2.0.32` — библиотека для работы с PDF.






##Слить ветку в main в Git можно так:

git checkout main - Переключитесь на main

git merge имя-ветки   - Слит нужную ветку


##Удалить локальную ветку:

git branch -d имя-ветки
